# 院标（学院 LOGO）资产

右上角院标是**可替换件**：换一个学院，只需要换这张图，不用动脚本。

## 换成你自己的院标（两步）

1. 把院标原图放到本目录，命名随意（建议 `logo_你的学院.png`）：

   - **必须未裁剪的完整图** —— 原稿里那些被拉扁、缺半截的图，投影出来就是"少半截子"
   - **透明底 PNG 最佳**，白底 PNG 在白底页面上会露出一个白方块
   - 分辨率不低于 300×200，长宽比随意，脚本会按高度等比算宽度
   - 判断有没有被裁过：`p:blipFill/a:srcRect` 的 l/t/r/b 裁剪值应全为 0（或无该节点） 节点

2. 改 `case/deco_config.json` 里这一行：

   ```json
   "logo": {
     "on": true,
     "image": "assets/logo_你的学院.png",
     "h": 0.56,
     ...
   }
   ```

然后照常跑第 4 步：

```bash
$PY scripts/ppt_deco.py _build/v白底.pptx _build/v装饰.pptx --config case/deco_config.json
```

## 位置与尺寸怎么定

`deco_config.json` 的 `logo` 段：

| 字段 | 含义 | 本案例取值 |
|---|---|---|
| `image` | 外部图片路径；`null` 则从 `source_slide` 那页深拷贝原图 | `assets/logo_示例_人工智能学院.png` |
| `source_slide` / `source_name` | 只在 `image: null` 时生效：从哪一页、哪个形状名取原图 | `1` / `null` |
| `h` | 院标高度（英寸）。**教师说"再大一点"就调这个** | `0.56` |
| `right` | 距页面右边缘 | `0.38` |
| `top` / `band_h` | 页眉带的顶边与高度，院标在其中垂直居中 | `0.14` / `0.73` |
| `ratio` | 历史兼容字段；现按图片真实比例计算 | `1.3745` |
| `skip` | 不放院标的页（封面、封底、目录） | `[1, 186]` |
| `match` | 判定"旧院标"的条件，符合就先删掉再放新的 | `t_max 1.0 / l_min 10.5 / w_max 2.5 / h_max 1.0` |

宽度由 `h × ratio` 算出，左边缘 = `实际页面宽度 − right − W`（16:9 页面宽 13.333 英寸）。
