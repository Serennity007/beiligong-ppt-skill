# PPT 批量改造工作流（六步）

适用于：已有 pptx，需要按"投影看得清、讲述有主线"做成体系改版。
每一步都可单独执行；第 5 步（放大字号）必须完整走完三个子脚本。

下面所有命令中的 `PY` 指管理版 Python：
`C:/Users/ztl/.workbuddy/binaries/python/envs/default/Scripts/python.exe`

---

## 准备

1. 备份底稿：`cp 原稿.pptx _build/底稿_备份.pptx`
2. 确认文件**没有被预览器 / Office / 微信打开**（被占用时写入会整体损坏，见《常见坑》）
3. 建目录：`_build/`（脚本与中间产物）、`preview/`（样张）

---

## 第 1 步：扫描版式骨架

```bash
$PY scripts/ppt_scan.py   底稿.pptx _build/scan.json          # 全量形状（位置/填充/字号）
$PY scripts/ppt_chrome.py 底稿.pptx _build/chrome.json --txt _build/chrome.txt
```

要摸清的四件事：

- **顶部横幅**：`w>12" 且 t<0.5"` 的 AUTO_SHAPE
- **标题 / 小标题 / 底栏 / 页码**：按位置判定（标题 `t<0.75" l<5" w>3"`；小标题位 `0.88"~1.25" l<1.6" w>8"`；底栏 `t>5.6" w>8"`）
- **卡片底色**：统计填充色 TOP 榜，找出浅绿铺底 / 灰带各有多少、多大
- **节点标签**：形状名含 `nodeTag`（可用 `--tag` 改）的角标，是后面分组的依据

输出一份"版式画像"，后面每一步都以它为依据，不要凭印象改。

---

## 第 2 步：标题分层（先出方案，人工核对）

教师最常见的意见："每个标题都不一样，这怎么讲？"

做法：**顶部横幅承载统摄主题，同一主题的连续页共用同一标题；原各页不同的大标题降为页内小标题。**

```bash
$PY scripts/ppt_titles.py _build/chrome.json _build/plan.json \
      --override case/title_override.json --txt _build/plan.txt
```

- 分组依据：节点标签（`nodeTag`），连续同标签页归为一组
- 标题改写走 `--override`（教师口径），未配置的沿用节点名
- `override` 里的 `self_titled`（总览 / 示例 / 部分收束）→ 不套统摄标题，保留页内自有标题
- **方案先出表核对**，确认后再执行第 3 步
- 若成品稿已把节点标签消费掉，脚本会提示"退化为按页内标题分组"，此时应回到底稿扫描

---

## 第 3 步：白底深字 + 写标题

```bash
$PY scripts/ppt_white.py 底稿.pptx _build/v白底.pptx \
      --config case/white_config.json --titles _build/plan.json --log _build/white_log.json
```

一次做掉：

- 页面背景浅绿铺底 → 纯白（**只改形状不换页面背景，投影仍是绿底**）
- 大面积浅绿/浅灰卡片 → 去掉填充
- 深绿主色 `006633` → `173404`，灰阶字整体加深一档
- 浅底上的白字 → 深色（深底/彩底上的白字保留）
- `--titles` 时：统摄标题写进页眉标题位；若该页原标题与统摄标题不同且没有小标题，原标题降为页内小标题

---

## 第 4 步：装饰件（目录 / 小标题色带 / 院标）

```bash
$PY scripts/ppt_deco.py _build/v白底.pptx _build/v装饰.pptx --config case/deco_config.json
```

三段互不影响，`on: false` 即可关掉：

- **目录页**：左侧"目 录 / CONTENT" + 绿色竖条，右侧 01–06 圆角编号块 + 标题 + 子题小字
- **页内小标题**：放进深绿色带，白字加粗（教师样例那种"主题栏"感）
- **院标**（可替换件）：`logo.image` 给了路径就用那张外部图，留 `null` 则从 `source_slide` 那页深拷贝原图。图必须**未裁剪**（无 `srcRect`）、透明底 PNG 最佳；各页被拉伸裁切的旧图会先删再放。换学院只需换 `assets/` 里的图 + 改这一行，见 [assets/README.md](../assets/README.md)

## 第 5 步：放大字号 + 加深颜色（必须实测回退）

```bash
$PY scripts/ppt_enlarge.py _build/v装饰.pptx _build/v放大.pptx \
      --map _build/size_map.json --config case/enlarge_config.json
$PY scripts/ppt_fit.py    _build/v放大.pptx --map _build/size_map.json --out _build/fit.json
$PY scripts/ppt_apply.py  _build/v放大.pptx --fit _build/fit.json --out 交付.pptx
```

- `ppt_enlarge.py`：分级放大（<11pt→≥14、<14pt→≥16、<18pt→≥19、<22pt→≥23、<26pt→≥27、更大→≥34）+ 颜色加深 + 行距收 1.0
- `ppt_fit.py`：调 PowerPoint 逐框测墨迹，越框按 100%→94%→88%→82%→76%→70% 逐档回退，**下限是放大前的原字号**
- `ppt_apply.py`：用 python-pptx 写回保存（不让 COM 保存，避免它顺手改写我们用 XML 塞进去的元素）

回退后仍越框的框，多是原稿就放不下，脚本会保持原状并列出清单，可再单独修（加宽框 / 单独缩该框字号）。

---

## 第 6 步：核验与交付

```bash
$PY scripts/ppt_verify.py 交付.pptx --fit _build/fit.json --json _build/verify.json
$PY scripts/ppt_export.py 交付.pptx --pdf 交付.pdf --png preview --png-pages 1,2,6,30,87
$PY scripts/ppt_shots.py  交付.pdf preview_small --dpi 110      # 可选，跨平台
```

必查项：

- 页数、页序完整（对比底稿；脚本直接读包里 `<p:sldId>` 计数）
- 白底上没有残留白字；深色块上的白字仍在（脚本会看文字框**背后**压的是什么颜色，不会把色带上的白字误判）
- 标题 / 小标题框零越框
- 院标覆盖全部内容页，旧图零残留
- 抽样渲染 4–6 页目检
