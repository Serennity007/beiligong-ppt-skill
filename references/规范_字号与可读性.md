# 规范：字号与可读性

来源：教师反馈"屏幕不清楚、字太小看不见"之后的整改做法。核心不是一把放大，而是**放大 + 实测回退**。

## 分级放大表（原值 → 目标）

| 原字号 | 目标 | 说明 |
|---|---|---|
| < 11pt | 14pt | 小注、页码一类 |
| 11–13pt | 16pt | |
| 14–17pt | 19–20.5pt | 正文下限抬到 19 |
| 18–21pt | 21.5–25.5pt | 正文主体 |
| 22–25pt | 27.5pt | 卡片标题 |
| 26–27pt | 31pt | |
| ≥ 28pt | 34pt | 统摄标题 |

公式：`×1.40 / ×1.25 / ×1.20 / ×1.18 / ×1.13 / ×1.10`，并设下限，结果取整到 0.5pt。

## 实测回退（关键）

放大后必须让 PowerPoint 逐框测墨迹：

```
over = max(框左-墨左, 框上-墨上, 墨右-框右, 墨下-框下)   # 单位 pt
```

- 允许 3pt 富余
- 越框就按 100% → 94% → 88% → 82% → 76% → 70% 逐档整体缩小该框
- **下限 = 放大前原字号**（即 k ≥ 原值/目标值），保证"只大不小"
- 退到下限仍越框的，是原稿就放不下，保持原状并列入清单

一次真实执行的分布：2684 个文字框，1705 个保持目标值，约 900 个按档回退，109 个退到原值，35 个原稿即越框。

## 腾空间的配套动作

- 行距 > 1.05 的段落统一收为 1.0
- 段前距、段后距清零
- 文本框内边距保持默认，不要为了塞字去缩小边距

## 放不下的框怎么单独修

按风险从低到高：

1. **加宽框**：右侧/下方有空位时优先（如百分比数字框 1.07"→1.38"）
2. **缩该框字号**：按框宽折算 `字号 = 72 × 框宽(英寸) / (字符数 × 1.06)`，取 min(现字号, 该值)
3. **拆行/删冗句**：内容型溢出（指导书要求：文字框放不下时先删冗句，不靠持续缩小字号塞满一页）
4. **该页重排**：图文关系本身太挤的（典型案例：一张底图 + 几十个小标签），单靠字号救不了，整页重排

## 交付前必查

- 页数、页序完整
- 标题 / 小标题框零越框
- 抽样渲染 4–6 页目检（目录页、普通内容页、图示密集页、部分分隔页各一）
- 确认没有"白底白字"（去底色后忘记改字色）
