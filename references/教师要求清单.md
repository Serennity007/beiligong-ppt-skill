# 教师要求清单（硬性验收标准）

来源：教师录音与现场反馈（2026-10-20，186 页《智能体安全》课件整改）。
这份不是"参考建议"，是**验收标准**——改造前先读，交付前用 `ppt_audit.py` 逐条过一遍。

每条格式：**教师原话 → 要求 → 落地做法 → 怎么判定（自动 / 人工）**

---

## A. 先停止执行的旧做法

| 编号 | 旧做法 | 本次纠正 | 判定 |
|---|---|---|---|
| A1 | 目录叠加内容说明、节点小目录、页段 | 目录只呈现主题与顺序 | 自动 `目录页` |
| A2 | 用任务对照表、关系台账代替总览 | 真正画出组成、层次和逻辑关系 | 人工 |
| A3 | 每页单独起标题，"无重复标题"当验收标准 | 同主题连续页共用统摄标题 | 自动 `统摄标题连续` |
| A4 | 把部分名、节点名缩在右上角 | 统摄主题放上方醒目位置 | 自动 `右上角不放文字` |
| A5 | 每页加"本页讲什么"、固定副标题、总结底栏 | 只保留页内小标题与必要结论 | 自动 `底部横幅`/定位信息 |
| A6 | 绿底、绿卡片、灰说明带、深色总结块 | 白底无填充 + 深色字 | 自动 `白底`/`去底块`/`深字` |
| A7 | 规定总页数、每组几页、图示配额 | 按内容需要合并删减，不设指标 | 人工 |

## B. 目录与总图

> "我让你给个总图，不是让你加一个小目录。"
> "你得先画一个总图，然后依照这个总图，我展开讲。"

| 编号 | 要求 | 落地做法 | 判定 |
|---|---|---|---|
| B1 | 目录只呈现报告结构 | 左侧"目 录 / CONTENT"+ 右侧编号块与主题名，删解释性小字 | 自动 `目录页` |
| B2 | 总图必须展示内容关系 | 画清对象由什么组成、各部分什么关系、后面按什么顺序展开 | 人工 |
| B3 | 不能把标题列表放进方框当总图 | 箭头要有明确含义（调用/反馈/约束/核验），并列关系用并列布局 | 人工 |
| B4 | 清理索引式页面 | 开篇对照页 → 总图；部分隔页的节点清单、页段、"本部分回答"全部删掉 | 自动 `编辑定位信息` |
| B5 | 关系台账退场 | 删 E 编号、"正文位置"、页码引用；有效关系提炼进总图 | 自动 `编辑定位信息` |

## C. 标题分层（教师最在意的一条）

> "每个标题都不一样，这怎么讲？"
> "小标题放在页里头。"

| 编号 | 要求 | 落地做法 | 判定 |
|---|---|---|---|
| C1 | 顶部横幅承载统摄主题，位置醒目、样式一致 | 统摄标题写进页眉标题位，深绿加粗 28–34pt | 自动 `统摄标题连续` |
| C2 | 同一主题下的连续页保留同一标题 | 按节点标签分组，连续同组共用 | 自动 `统摄标题连续`（孤立页比例） |
| C3 | 页内小标题说明当前具体论题，靠近对应图文 | 副标题位 / 深绿色带白字 | 自动 `页内小标题` |
| C4 | 不要把全篇写成同一个空泛标题 | 统摄标题必须具体（对象 + 专业概念） | 人工 |
| C5 | 标题删口语、制作说明、"几个方面""一些思考" | 同义反复改写合并 | 人工 |

## D. 案例直接讲问题与方案

> "案例一……问题是什么？解决方案是什么？"

| 编号 | 要求 | 落地做法 | 判定 |
|---|---|---|---|
| D1 | 先简短事实交代事件 | 只保留材料能支持的经过和影响 | 自动 `案例三件套`（查"问题""方案/防控/措施"是否都在） |
| D2 | 清楚标出"问题"和"防控方案" | 用图或分栏标出，问题/方案各占一块 | 自动 `案例三件套` |
| D3 | 不要先堆时间线、来源、评分、关系索引 | 结论前置 | 人工 |
| D4 | 实际处置与建议分开写 | "已采取的处置" / "防控方案（建议）" | 人工（查是否把建议写成对方已实施） |

## E. 白底、深字、完整院标

> "把绿色的底子去掉……字颜色弄深一点。"
> "人工智能学院这个院标都少半截子。"

| 编号 | 要求 | 落地做法 | 判定 |
|---|---|---|---|
| E1 | 全页背景、正文卡片、文字底带统一白底或无填充 | 页面背景刷白 + 去浅绿/浅灰铺底 | 自动 `白底` `去底块` |
| E2 | 去底同步把白字改深色 | 亮度判定 + 背后色判定 | 自动 `深字` |
| E3 | 顶部横幅白底 + 深色标题 + 细线 | 细线 0.75–1.25pt 深绿 | 人工 |
| E4 | 底部横幅没必要的删 | 有底部条的页占比偏高即预警 | 自动 `底部横幅` |
| E5 | 图表里的白字深底同步处理；位图固化的底块要重绘 | 不只是改幻灯片背景 | 人工 |
| E6 | 院标换完整原图、等比缩放、完整适应画框 | 无 `srcRect`、宽高比与源图一致 | 自动 `院标完整` |
| E7 | 实景照片与院标保留原色 | 不做影响信息的统一去色 | 人工 |

## F. 版面与可读性

> "底下不一定每一页都得有横幅。没有必要的就不要加。"
> "正文位置、P几P几这些都删掉。"

| 编号 | 要求 | 落地做法 | 判定 |
|---|---|---|---|
| F1 | 删"P几""正文位置"等编辑定位信息 | 页脚页码可留，但不进标题 | 自动 `编辑定位信息` |
| F2 | 放不下时先删冗句、调图文、拆内容，**不靠持续缩小字号** | 放大后逐框实测回退 | 自动 `字号下限` + `越框`（配 fit.json） |
| F3 | 检查文字与文本框、外层卡片、连线、图片、页面边界的关系 | 不能只查框内 | 自动 `越框` + 人工目检 |
| F4 | 用对齐、间距、留白组织版面 | 不靠铺色 | 人工 |

## G. 执行顺序与交付检查

执行顺序（**先让老师看到新结构，不要全部重做完才交审看稿**）：

1. 白底深字；修复院标；删导读、页段、无必要底栏
2. 重做目录和总图，定展开关系
3. 统摄标题移到上方，具体论题改页内小标题
4. 案例整理为事件、问题、防控方案，区分实际处置与建议
5. 合并重复页、调图文，逐页查可读性与遮挡，导出审看稿

交付八问（人工逐条答）：

- [ ] 听众能从目录看清报告主题、从总图看清内容关系？
- [ ] 展开页沿总图的顺序与分类讲述？
- [ ] 统摄标题醒目，同一主题保持连续？
- [ ] 页内小标题明确对应当前图文？
- [ ] 案例能直接找到核心问题和防控方案？
- [ ] 还有绿/灰文字底块、浅色字、残缺院标吗？
- [ ] 还有"本部分回答""正文位置"、页段、编辑编号吗？
- [ ] 有文字越框、贴边、连线压字、图注遮挡、过密小字吗？

验收围绕**报告结构、讲述连贯性、专业表述、投影可读性**，不再以页数、图数或标题唯一性计数。
改稿台账留在独立文件，不进报告正文。

## 自动体检

```bash
$PY scripts/ppt_audit.py 成品.pptx --json _build/audit.json --md _build/audit.md
```

能自动判的项：白底、去底块、深字、院标完整、统摄标题连续、页内小标题、右上角不放文字、
底部横幅、编辑定位信息、案例三件套、字号下限、越框（配 `--fit`）。
判不了的（总图画没画对、讲述顺序、口语化标题、连线压字）会作为**人工核对项**列在报告末尾，逐条勾。
